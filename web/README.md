# Cadence web client

React + TypeScript + Vite single-page app for Cadence. See the [repo root README](../README.md)
for the product pitch, quickstart, and configuration reference, and
[CONTRIBUTING.md](../CONTRIBUTING.md) for the full development setup.

Quick reference:

```bash
npm install
npm run dev        # dev server, proxies /api to a backend on :8000
npm run lint
npm run typecheck
npm test           # component/unit tests (Vitest)
npm run test:e2e   # end-to-end (Playwright), boots the real backend in demo mode
npm run build
```
